# 页面导航

本仓库是一个纯静态网页合集，每个页面都是独立目录，可直接打开或部署到 GitHub Pages。

## 页面列表

| 页面 | 路径 | 说明 |
| ---- | ---- | ---- |
| 星露谷农场 | [farm/](./farm/) | 仿 QQ 农场的种植小游戏，支持种菜、养鱼、开地 |
| Echoes of the End | [echoes_of_the_end/](./echoes_of_the_end/) | 末日生存游戏，安全屋 + 地图探索 |

## 访问方式

- 本地:直接双击任意页面目录下的 `index.html` 打开
- 在线:将本仓库部署到 GitHub Pages 后，访问对应目录路径

## 添加新页面

新增页面时，在根目录下新建独立目录并放入 `index.html`，然后在表格中追加一行即可，例如:

```
| 新页面名 | [目录名/](./目录名/) | 一句话说明 |
```
