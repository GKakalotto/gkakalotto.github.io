#  Echoes of the End — 末日生存

> 当文明崩塌，成都只剩下空荡的街道和求生的你。

## 项目简介
- 一款以**成都为背景**的纯前端末日生存游戏。
- 从破旧安全屋醒来，管理生存状态，在灾后的城市中外出探索、收集物资。
- 基于 Vue 2 构建，纯静态页面，无后端，浏览器直接运行。

## 核心特色
-  **真实时间系统**：1 游戏天 = 现实 1 小时，四季更替(秋→冬→春→夏)，每天随机天气，温度随季节、昼夜和天气实时变化。
-  **成都地图探索**：26 个真实地名(华西医院、伊藤洋华堂、四川大学、天府广场地铁站…)，按真实方位布局，步行前往，距离决定耗时。
-  **生存状态管理**：生命、饱食、水分、理智、精力、体力、健康、力量、速度、知识十项数值，维持生存平衡。
-  **安全屋养成**：破床、篝火、工作台、雨水收集器、仓库等家具待解锁;室外还有狗窝和防御栅栏。
-  **本地存档**：基于浏览器 `LocalStorage`，自动保存进度，刷新不丢档。
-  **秒级部署**：纯静态网页，丢到 GitHub Pages 即可运行。

## 玩法流程
1. 在安全屋醒来，查看当前季节、天气与生存状态。
2. 推开大门进入成都地图。
3. 点击地点确认出发，步行耗时内游戏时间持续推进。
4. 返回安全屋休整，解锁家具强化生存。
