#  纯文字版仿 QQ 农场（摸鱼特供版）

> “只要没有图片，老板就看不见我在摸鱼。”

##  项目简介
- 这是一款专为上班族打造的**纯文字版**仿 QQ 农场小游戏。
- 抛弃了所有花里胡哨的图片、动画和 Flash，只保留最核心的玩法。
- 界面极简，加载秒开，即使老板突然出现在身后，你也只需一秒切回代码编辑器。

##  核心特色
- **极致隐蔽**：纯 HTML/CSS/JS，无任何外部图片资源。
- **经典种植**：开垦土地、播种、浇水、等待、收获全流程；收获后土地可能干枯，偶尔还会掉落种子。
- **佛系养鱼**：投放鱼苗、坐等收鱼，看着文字里的鱼儿慢慢长大。
- **农场养殖**：养殖动物，喂牧草、收产物，成熟后还能收获成体。
- **经营成长**：商店采购、背包回收、仓库出售；物品可加锁防止误卖；收获获取经验升级，升级奖励金币。
- **本地存档**：基于浏览器 `LocalStorage`，刷新不丢进度，关闭浏览器也能保留你的农场。
- **秒级部署**：纯静态网页，直接丢到 GitHub Pages，随时随地打开链接即可摸鱼。
